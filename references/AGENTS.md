# Reference Rules

External projects under `references/upstream/` are read-only design references.

Rules:

- Do not copy source code directly from reference projects.
- Use upstream projects only to understand architecture, workflow, terminology, trade-offs, and evaluation ideas.
- Summarize useful ideas into `references/design-notes/` before using them in project design.
- Prefer project-local design decisions over blindly following upstream implementations.
- Keep attribution clear when discussing design inspirations.
